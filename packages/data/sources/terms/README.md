# Translation drafts

Partial language contributions are welcome through a pull request. Follow
[CONTRIBUTING.md](../../../../CONTRIBUTING.md) for examples, licensing, provenance,
human review and the steps required to enable a new locale.

- `uk.draft.json`: editor proposals, keyed by English source term.
- `uk.machine.json`: machine-assisted proposals, used when there is no editor proposal.
- Proposed new languages: `<lang>.draft.json` and, if applicable, `<lang>.machine.json`.

Every draft is unreviewed. A merged PR or successful JSON check is not expert review.
The current build imports only the Ukrainian draft files; proposed files for another
language need explicit runtime and pipeline integration before they are shipped.

Anatomical-name data contributions are offered under CC BY-SA 4.0 to the extent the
contributor holds relevant rights. Record external sources and any machine assistance
in the PR. Public-domain terms remain public domain; no licence approval is implied
for imported material merely by placing it in this directory.
